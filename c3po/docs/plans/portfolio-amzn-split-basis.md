# AMZN: explicit historical quantity basis

The owner confirmed that the historical AMZN acquisition quantities are already restated in post-20:1 units. Multiplying those quantities by pre-split raw closes inflates historical value and creates an artificial loss at the split boundary.

This change uses split-only normalization for AMZN before the 2022-06-06 trading session. Source: https://www.sec.gov/Archives/edgar/data/1018724/000101872422000009/amzn-20220309.htm (20:1; adjusted trading starts June 6). Raw closes are divided by 20 only when the account explicitly declares restated AMZN units. Provider adjusted_close is deliberately not used because it may incorporate dividends. The ledger, acquisition totals, fees, and current valuation remain unchanged.

Activation requires C3PO_PORTFOLIO_SPLIT_ADJUSTED_SYMBOLS=AMZN in the API environment, after approval of the code and configuration together. Default is empty, with no inferred basis. With an unknown basis, affected historical periods return N/D instead of a fabricated result. A ledger in original units with the explicit 20:1 event dated June 6 keeps raw historical closes. A conflicting explicit event plus restated declaration refuses the affected historical calculation. Mixed quantity bases require separate reconciliation; no automatic inference or ledger rewrite is allowed. This is narrowly scoped to the confirmed AMZN 2022 action, not a general corporate-actions engine.

Validation uses synthetic prices and quantities only: equivalent original/restated ledgers, June loss based on economically continuous prices, exact trading boundary, ambiguous and double-adjustment refusal, other symbols unchanged, and no persisted ledger changes. Current summary remains independently calculated; N/D historical results must not be presented as proof that current holdings are reconciled.

No production configuration change, migration, merge or deployment has been executed by this PR. Main remains frozen. This backend change requires a separate Fable disposition and updated recertification evidence before any authorized deployment; it must not silently replace the current rev4 base or displace BAR/rev4 deadlines. Readback must compare monthly/quarterly/yearly aggregates and month counts, plus acquisition totals and current quantities, against an independent reconciliation. No corrected personal performance amount is claimed by the synthetic tests.
